# 显存带宽、核心与时钟频率

这一课讲 GPU 的速度从何而来，内容包括显存带宽、核心数量、时钟频率、能耗和专用硬件。

## 显存带宽

GPU 要有数据才能干活，而数据来自显存。显存带宽指的是每秒能在显存和 GPU 之间搬运多少数据，单位通常是 GB/s。

## 一个小例子

假设一块 GPU 有 4 个核心，每个核心都要先拿到数据才能开始工作。

如果显存一次只能给一个核心送数据，那么第一个核心开始干活时，另外三个只能干等。接着第二个核心拿到数据，然后是第三个、第四个。这样 4 个核心里每次只有 1 个在工作，GPU 的利用率很低。

现在假设显存能同时给 4 个核心送数据。所有核心一起开始，并行运行，谁都不用等。

数据来得足够快，GPU 才能快起来；否则它只能等。这就叫“显存瓶颈”。

## 消费级 GPU 与数据中心 GPU

现代 GPU 有两类：

- 消费级 GPU，比如 RTX 显卡，用于游戏和日常使用。
- 数据中心 GPU，比如 H100 或更新的 Blackwell 架构 GPU，用于 AI 和大规模计算。

两类 GPU 都可能有很多核心，有时架构也相近。最大的区别在于显存。

数据中心 GPU 使用“HBM 显存”。HBM 速度极快，紧挨着 GPU 芯片，能在极短时间内送出海量数据。

> [!NOTE]
> HBM 有 HBM3、HBM3e 等版本，HBM4 也即将问世。

消费级 GPU 通常使用 GDDR6 或 GDDR6X 显存，速度也很快，但比不上 HBM。

两块 GPU 的纸面参数可能差不多，但显存带宽更高的那块能让核心一直有活干，另一块则可能在等数据。这正是数据中心 GPU 在 AI 工作负载上如此强大的主要原因之一。

## 影响显存带宽的因素

影响显存带宽的主要因素有三个：

- 总线位宽就像道路的宽度。路越宽，同一时间能通过的数据越多。
- 显存速度就像道路的限速。路再宽，车速慢了也会拥堵。
- 显存技术是现代 GPU 之间差别最大的地方。HBM 就像专为数据修建的高速公路，GDDR 则更偏通用。

GPU 的性能不只取决于核心，还取决于核心拿到数据的速度。再强的 GPU，如果总在等显存，也发挥不出实力。

## 核心多不一定就更快

数据到达之后，GPU 就要处理它，每个核心都在执行指令。核心越多性能越好，听起来理所当然，但事实并非总是如此。

假设有两块 GPU，第一块有 100 个核心，第二块有 200 个核心。两者运行同一个任务，共有 200 次运算。

- 第一块 GPU 每次处理 100 次运算，所以需要两轮。
- 第二块 GPU 一轮就能处理完全部 200 次运算。

现在再算上每轮所需的时间：

- 第一块 GPU 每轮要 1 秒，所以 2 秒就完成了。
- 第二块 GPU 每轮要 4 秒，所以要 4 秒才完成。

第二块 GPU 核心更多，却更慢。所以还得知道每个核心有多快。

## 时钟频率

时钟频率就是每个核心执行指令的快慢。

性能同时取决于两件事：

- 核心越多，并行度越高。
- 时钟频率越高，每个核心越快。

只要其中一项太低，就会拖累整个系统。关键在于两者平衡。

## 两种设计方向

到 2026 年前后，GPU 分成了两种设计方向：一类面向游戏和日常使用，另一类面向 AI 和大规模计算。

- 数据中心 GPU 往往核心数量非常多，但时钟频率较低。
- 消费级 GPU 往往时钟频率更高，但核心较少。

笼统地说，两者没有高下之分，只是各自针对不同的工作负载做了优化。

## 能耗

性能总是和能耗挂钩。核心更多、时钟频率更高，也就意味着更耗电。所以在性能和能效之间，总要有所取舍。

“哪块 GPU 更好？”这个问题本身就问错了。更好的问法是：“在哪方面更好？”

## 专用硬件

现代 GPU 不只是一堆通用核心，还配有专用硬件。

“Tensor Core”就是一个例子。它是为特定计算（尤其是 AI 计算）打造的单元。遇到合适的工作负载，它能大幅提速，但前提是工作负载和硬件对得上。

## 吞吐量

光看核心数量、时钟频率和 TFLOPS，反映不了全貌。更该问的是：GPU 在一定时间内能完成多少工作？这就是“吞吐量”。

吞吐量同样取决于很多因素，比如计算类型、精度和架构。没有哪个单一数字能说明一切。

## 小结

GPU 需要快速的显存、足够的核心、足够的速度、合理的能耗，有时还需要专用硬件。只有这些因素相互平衡，才能发挥出真正的性能。

GPU 的性能不是某一个数字，而是显存、算力、能效和专用硬件协同工作的一整套系统。明白了这一点，你就能更轻松地看懂规格，也更容易理解 CUDA 的各种概念。

## 术语表

- 显存带宽（memory bandwidth）：每秒能在显存和 GPU 之间搬运的数据量。
- GB/s（gigabytes per second，吉字节每秒）：每秒搬运十亿字节；RTX 4090 约为 1,000 GB/s，H100 最高约 3,350 GB/s。
- 核心（core）：执行指令的单元；它就像一个工人，要先拿到数据才能开工。
- 并行（parallel）：很多核心同时工作，而不是一个接一个。
- 显存瓶颈（memory bottleneck）：显存送数据的速度跟不上，GPU 核心只能干等。
- RTX：Nvidia 面向游戏和日常使用的消费级 GPU 系列，比如 RTX 4090。
- H100：Nvidia 2022 年推出的 Hopper 架构数据中心 GPU，配有 80 GB HBM3 显存。
- Blackwell：Nvidia 在 Hopper 之后的数据中心架构，为大规模 AI 打造。
- AI（人工智能）：从数据中学习的软件；训练时要搬运海量数据，所以显存带宽非常重要。
- HBM（High Bandwidth Memory，高带宽显存）：数据中心 GPU 使用的极快显存，紧挨着 GPU 芯片。
- GDDR / GDDR6 / GDDR6X：消费级 GPU 使用的显存家族；很快，但比不上 HBM。
- 工作负载（workload）：程序交给 GPU 的那类工作，比如训练模型或运行游戏。
- 总线位宽（bus width）：显存同一时刻能搬运的数据量，就像道路的宽度。
- 显存速度（memory speed）：每个显存引脚传送数据的速度；例如 384 位总线、21 Gbps，得到 384 × 21 / 8 = 1008 GB/s。
- 指令（instruction）：核心执行的一条基本命令，比如一次加法或乘法。
- 时钟频率（clock speed）：每个核心执行指令的快慢。
- 能效（efficiency）：GPU 每消耗一瓦电能完成多少工作。
- 取舍（trade-off）：为了多得到一样东西而牺牲另一样，比如牺牲速度换取更低的功耗。
- Tensor Core：为特定计算打造的专用硬件，尤其用于 AI。
- TFLOPS：每秒万亿次浮点运算，是一个峰值指标，实际程序很少能达到。
- 吞吐量（throughput）：GPU 在一定时间内能完成的工作量。
- 精度（precision）：每个数用多少位来存储，比如 FP32 或 FP16；位数越少，吞吐量越高，但精确度越低。
- 架构（architecture）：GPU 的整体设计，决定了核心、显存和专用单元怎样配合工作。
- CUDA：NVIDIA 的平台，用来编写在 NVIDIA GPU 上运行的程序。
