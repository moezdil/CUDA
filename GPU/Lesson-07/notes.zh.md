# 显存带宽、核心与时钟频率

这一课讲是什么让 GPU 变快。内容包括显存带宽、核心数量、时钟频率、能耗和专用硬件。

## 显存带宽

GPU 需要数据才能干活，而数据来自显存。显存带宽就是每秒钟能在显存和 GPU 之间搬运多少数据。

## 一个小例子

假设有一个 GPU，它有 4 个核心。每个核心都要先拿到数据才能开始工作。

假设显存一次只能给一个核心送数据。第一个核心开始干活，另外三个只能等着。然后第二个核心拿到数据，接着是第三个，再是第四个。所以 4 个核心里每次只有 1 个在工作。GPU 没有被高效利用。

现在假设显存能同时给 4 个核心送数据。所有核心一起开始，并行运行，谁都不用等。

GPU 只有在数据来得足够快时才快，否则它就只能等。这叫作“显存瓶颈”。

## 消费级 GPU 与数据中心 GPU

现代 GPU 有两类：

- 消费级 GPU，比如 RTX 显卡，用于游戏和日常使用。
- 数据中心 GPU，比如 H100 或更新的基于 Blackwell 的 GPU，用于 AI 和大规模计算。

两类 GPU 都可以有很多核心，有时架构也差不多。最大的区别在于显存。

数据中心 GPU 使用 “HBM 显存”。HBM 速度极快，离 GPU 芯片非常近。它能非常快地送出海量数据。

> [!NOTE]
> HBM 有 HBM3、HBM3e 等版本，HBM4 也快要来了。

消费级 GPU 通常使用 GDDR6 或 GDDR6X 显存。它们也很快，但比不上 HBM。

两个 GPU 在纸面上可能看起来差不多。显存带宽更高的那个，能让核心一直有活干；另一个则可能要等数据。这是数据中心 GPU 在 AI 工作负载上如此强大的主要原因之一。

## 什么会影响显存带宽

影响显存带宽的主要因素有三个：

- 总线位宽就像道路的宽度。路越宽，同一时间能运的数据越多。
- 显存速度就像道路的限速。就算路很宽，车开得慢也会堵。
- 显存技术是现代 GPU 之间差别最大的地方。HBM 就像专门为数据修建的高速公路，GDDR 则更通用。

GPU 的性能不只取决于核心，还取决于核心拿到数据有多快。就算是最强的 GPU，如果一直在等显存，也会变弱。

## 核心多不一定就更快

数据到了之后，GPU 要处理它。每个核心都在执行指令。核心越多性能越好，听起来理所当然，但事实并不总是这样。

假设有两个 GPU。第一个有 100 个核心，第二个有 200 个核心。两者运行同一个任务，这个任务有 200 次运算。

- 第一个 GPU 每次处理 100 次运算，所以需要两轮。
- 第二个 GPU 一轮就能处理完全部 200 次运算。

现在再加上每一轮的时间：

- 第一个 GPU 每轮要 1 秒，所以 2 秒就完成了。
- 第二个 GPU 每轮要 4 秒，所以要 4 秒才完成。

第二个 GPU 核心更多，却更慢。所以我们还需要知道核心有多快。

## 时钟频率

时钟频率就是每个核心执行指令的快慢。

性能同时取决于两件事：

- 核心越多，并行度越高。
- 时钟频率越高，每个核心越快。

只要其中一个太低，就会拖累整个系统。目标是保持平衡。

## 两种设计方向

到 2026 年前后，GPU 沿着两种设计方向发展。一些是为游戏和日常使用打造的，另一些是为 AI 和大规模计算打造的。

- 数据中心 GPU 往往核心数量非常多，但时钟频率较低。
- 消费级 GPU 往往时钟频率更高，但核心较少。

总的来说，没有哪个更好。它们各自针对不同的工作负载做了优化。

## 能耗

性能总是和能耗绑在一起。核心更多、时钟频率更高，也意味着更耗电。所以性能和能效之间总要做取舍。

“哪个 GPU 更好？”这个问题问错了。更好的问法是：“在什么方面更好？”

## 专用硬件

现代 GPU 不只是一堆通用核心，它们还有专用硬件。

“Tensor Core” 就是一个例子。它是为特定计算打造的单元，尤其是在 AI 中。遇到合适的工作负载，它能大大提速。但前提是工作负载要和硬件匹配。

## 吞吐量

光看核心数量、时钟频率和 TFLOPS，说明不了全部情况。更好的问题是：GPU 在一定时间内能完成多少工作？这叫作“吞吐量”。

吞吐量也取决于很多因素，比如计算的类型、精度和架构。没有哪一个数字能说明一切。

## 小结

GPU 需要快速的显存、足够的核心、足够的速度、合理的能耗，有时还需要专用硬件。只有这些因素保持平衡，才能拿到真正的性能。

GPU 的性能不是一个单一的数字。它是一个系统，显存、算力、能效和专用硬件在其中一起工作。了解这一点，你就能更轻松地看懂规格，也更容易理解 CUDA 的概念。

## 术语表

- 显存带宽（memory bandwidth）：每秒钟能在显存和 GPU 之间搬运多少数据。
- 显存瓶颈（memory bottleneck）：显存送数据不够快，GPU 核心只能等着。
- HBM：数据中心 GPU 使用的极快显存，离 GPU 芯片非常近。
- GDDR6：消费级 GPU 使用的快速显存，但比不上 HBM。
- 总线位宽（bus width）：显存同一时间能搬运多少数据，就像道路的宽度。
- 时钟频率（clock speed）：每个核心执行指令的快慢。
- Tensor Core：为特定计算打造的专用硬件，尤其用于 AI。
- 吞吐量（throughput）：GPU 在一定时间内能完成多少工作。
