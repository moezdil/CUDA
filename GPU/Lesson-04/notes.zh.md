# GPU 与 GPU 芯片

这一课讲 GPU 芯片和 GPU 的区别。两者密切相关，但并不是一回事。

## GPU 芯片

GPU 芯片就是实实在在的那块硅片，所有计算都在这里完成。它本身没有散热装置和接口，也没有外接的显存模块。

芯片内部包括：

- 执行并行任务的计算单元  
- 管理数据流动的控制器  
- 统筹协调各部分的内部逻辑  

芯片才是真正的“发动机”。

## 芯片名称

从芯片名称可以看出它属于哪种架构。例如：

- GF100 → Fermi  
- GA100 → Ampere  

名称的前缀就代表架构。

> [!NOTE]
> 到 2026 年前后，现代 GPU 依然沿用这种命名规则。

## GPU

GPU 是你实际使用的完整产品，是围绕芯片搭建起来的一整套系统，包括：

- 芯片本身  
- VRAM（与芯片相连的显存）  
- 供电部件  
- 输出接口（比如 HDMI 或 DisplayPort）  
- 散热系统  

所以 GPU 就是芯片，再加上让它能真正用起来的所有部件。

## 消费级 GPU

GeForce GPU 面向普通的使用环境：

- 台式机  
- 笔记本电脑  
- 个人工作站  

这些系统没有专门的散热设施，GPU 必须自己解决发热问题。所以大多数消费级 GPU 都配有：

- 很大的散热片  
- 多个风扇  
- 一眼就能看到的散热结构  

它们自成一体，必须能在普通的电脑机箱里正常工作。

## 数据中心 GPU

A100 基于 Ampere 架构，芯片是 GA100。但整块 GPU 看起来和 GeForce 显卡大不一样：它没有风扇。

数据中心 GPU 装在服务器机架里，散热由 GPU 外部负责：

- 气流由整机系统提供  
- 散热在机架层面统一解决  

这样 GPU 本身就更简单、更紧凑，也更适合大规模部署。

## 一句话说清区别

GPU 芯片是大脑，GPU 是一整套系统。

芯片 = 发动机  
GPU = 整台机器  

## 为什么这很重要

- 架构描述的是芯片，而不是整个产品  
- 性能的基础在芯片层面  
- 实际表现取决于整个 GPU 系统  

如果把两者混为一谈，你可能会误读：

- 规格  
- 性能对比  
- 甚至 CUDA 的行为  

弄清这一点，后面更深入的 CUDA 内容就更容易理解了。

## 术语表

- GPU 芯片（GPU chip）：实实在在的那块硅片，所有计算都在这里完成，没有散热装置也没有接口。
- 硅片（silicon）：制造芯片的材料；GA100 就是一块集成了大约 540 亿个晶体管的硅片。
- 架构（architecture）：芯片的设计，也就是它的各种单元、显存通路和控制器是怎样组织的。
- 前缀（chip name prefix）：芯片名称开头的几个字母，代表它的架构，比如 GA 代表 Ampere。
- Fermi：Nvidia 的一种架构，芯片名称形如 GF100。
- Ampere：Nvidia 的一种架构，芯片名称以 GA 开头，比如 A100 里的 GA100。
- GA100：A100 里的芯片；G 代表 GPU，A 代表 Ampere。
- GPU：围绕芯片搭建的完整产品，带有显存、供电部件、输出接口和散热。
- VRAM：与 GPU 芯片相连的显存。
- 供电部件（power delivery）：显卡上的一组部件，把电源送来的电转换成芯片所需的稳定电压。
- 输出接口（output interfaces）：GPU 上的端口，比如 HDMI 或 DisplayPort。
- 散热（cooling）：把芯片产生的热量带走，要么靠显卡上的风扇，要么靠服务器里的气流。
- GeForce：Nvidia 的消费级 GPU，自带散热片和风扇。
- 散热片（heatsink）：消费级 GPU 用来给自己散热的部件。
- 电脑机箱（PC case）：容纳台式电脑各个部件的箱子；消费级 GPU 必须在机箱里自己散热。
- A100：Nvidia 的数据中心 GPU，使用 GA100 芯片，自己没有风扇。
- 服务器机架（server rack）：安装数据中心 GPU 的地方，散热在机架层面解决，而不是靠 GPU 自己。
- 气流（airflow）：服务器自身风扇吹过机身的空气，用来给里面无风扇的 GPU 散热。
- 规格（spec）：GPU 公开的技术参数，比如芯片名称、核心数量或显存大小。
- TechPowerUp：列出 GPU 规格的网站，每款 GPU 的页面都链接到它所用的芯片。
