# 架构与芯片

这一课讲架构和 GPU 里真实芯片之间的关系。一个架构不是一颗芯片，而是一组共享同一基础设计的芯片家族。

## 一个架构，多颗芯片

以 Ada Lovelace 架构为例。它包括几颗不同的芯片，比如：

- AD102  
- AD103  
- AD104  

前缀 “AD” 把它们都和同一个架构联系起来。还没看任何规格，你就知道它们是一家人。

## 设计相同，规模不同

同一架构的芯片会用在不同的地方。有些用于高端 GPU，有些用于中端或更小的系统。

例如，AD102 通常用在顶级 GPU 上，AD104 则更可能用在更小、更省电的显卡上。所以 Nvidia 会把同一个设计放大或缩小，做出不同规模和能力的产品。

## 架构不同，工作也不同

并不是所有架构都为同一类工作而生。比较一下 Ada Lovelace 和 Hopper：

- Ada 主要用于消费级 GPU，比如游戏、台式机和创意工作。  
- Hopper 用于数据中心、AI 训练和大规模计算。  

所以区别在于用途，而不只是性能。有些架构面向图形和交互式工作，有些面向海量的并行计算。这就是为什么你在普通电脑里看不到基于 Hopper 的 GPU。

## 一个外观上的线索

> [!NOTE]
> 显卡的外观是个有用的线索，但不是严格的规则。

数据中心 GPU 通常看起来很朴素，看不到风扇。它们装在服务器里，靠气流、机架和整个系统来散热。

消费级 GPU 有很大的散热系统和好几个风扇。它们装在普通的电脑机箱里，所以必须自己处理热量。

## 同一颗芯片，表现也可能不同

一颗芯片不等于只有一种用途。同一颗芯片可以以不同的形式出现。厂商可以：

- 关闭一部分核心  
- 修改功耗上限  
- 调整时钟频率  

所以两个用同一颗芯片的 GPU，表现不一定相同。

## 板卡合作伙伴

Nvidia 并不会自己生产每一张最终的 GPU。像 ASUS、MSI 或 Gigabyte 这样的公司会拿同一颗芯片，做出自己的版本。它们会改动这些地方：

- 散热设计  
- 供电配置  
- 加速（boost）行为

## 完整的图景

架构是一个基础设计。它包含几颗芯片，分别按不同的用途调整规模。然后厂商再加入自己的变化。所以一个 GPU 由这些组成：

- 一个架构  
- 一颗具体的芯片  
- 某个厂商自己的实现  

## 为什么这很重要

这能让你更容易看懂 GPU 的名字。它能帮你理解为什么两个 GPU 表现不同，以及一个 GPU 处在什么位置。不了解这些，等你深入学习 CUDA 时，就很容易误解性能和硬件的行为。

## 术语表

- 架构（architecture）：一组芯片家族共享的基础设计。
- 前缀（prefix）：芯片名称开头的几个字母，比如 AD，它把芯片和架构联系起来。
- Ada Lovelace：Nvidia 的一种架构，主要用于消费级 GPU，芯片有 AD102 等。
- Hopper：Nvidia 的一种架构，用于数据中心、AI 训练和大规模计算。
- 时钟频率（clock speed）：厂商可以调整的一项设置，所以用同一颗芯片的 GPU 表现可能不同。
- 板卡合作伙伴（board partner）：像 ASUS、MSI 或 Gigabyte 这样的公司，用 Nvidia 的芯片做出自己的 GPU。
- 厂商自己的实现（vendor-specific implementation）：某个厂商围绕一颗芯片做出的自己版本的 GPU。
