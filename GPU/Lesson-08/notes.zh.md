# 认识一块真实的 GPU

这一课教你查出一块真实 GPU 的架构和类别，并说明为什么核心数量容易误导人，以及外观设计能透露哪些线索。

## 查一下这块 GPU

用 GPU 的名字加上“TechPowerUp”来搜索。比如搜“A100 TechPowerUp”或“RTX 3090 TechPowerUp”，然后点开一个结果。

页面上会列出一大堆数字和规格，不必全部看懂。只需关注两件事：架构和产品类别。

## 架构与类别

RTX 3090 采用 Ampere 架构，属于 GeForce 系列。也就是说，它面向消费级用途，比如玩游戏或个人工作站。

A100 同样采用 Ampere。这两块 GPU 架构相同，用途却不一样。

- 架构告诉你 GPU 是怎样构建的。
- 类别告诉你它用在什么地方。

> [!NOTE]
> 较老的资料常把数据中心类别叫作“Tesla”。Nvidia 较新的叫法（2026 年前后）是 Data Center GPU 或 AI GPU。

所以，RTX 3090 和 A100 虽然都是 Ampere，面向的却是完全不同的领域。RTX 3090 针对游戏和日常使用做了优化；A100 则面向 AI 工作负载、云基础设施和大规模系统。

## 不要只比较核心数量

7000、10000 这样的核心数量看上去很有说服力，其实容易误导人。因为它们通常只统计一种核心，往往是单精度单元，并没有涵盖 GPU 里的全部硬件。

现代 GPU 里有多种计算单元，Hopper、Blackwell 这类较新的架构尤其如此。光看核心数量，看不到全貌。

## 外观设计能给你提示

A100、H100 这类数据中心 GPU 通常看不到风扇。它们装在服务器里，由服务器负责散热。

RTX GPU 带有大风扇和整套散热系统。它们是为台式机和工作站设计的，必须自己解决散热问题。

由此可以得到一个简单的判断方法：

- 看得见大型散热装置，这块 GPU 多半是消费级的。
- 没有风扇的紧凑模块，多半是数据中心 GPU。

> [!TIP]
> 这不是硬性规则，但多数情况下都管用。

## 问对问题

你不必看懂每一个数字，而是要问自己这几个问题：

- 这块 GPU 用的是什么架构？  
- 它属于哪个类别？  
- 它是为解决哪类问题而设计的？  

有了这些答案，其余的规格也就好理解了。做 CUDA 和 GPU 相关的工作时，知道一块 GPU 是做什么用的，和了解它的规格同样重要。

## 术语表

- TechPowerUp：一个查询 GPU 规格的网站。用 GPU 名字加上“TechPowerUp”搜索，就能找到对应的页面。
- 规格（spec）：GPU 公开的某一项技术参数，比如核心数量、显存容量或时钟频率。
- RTX 3090：2020 年推出的 GeForce GPU，基于 Ampere，有 10,496 个核心和 24 GB GDDR6X 显存。
- A100：2020 年推出的 Ampere 数据中心 GPU，有 6,912 个单精度核心和 40 GB 或 80 GB HBM 显存。
- 架构（architecture）：GPU 是怎样构建的。RTX 3090 和 A100 都采用 Ampere。
- Ampere：Nvidia 2020 年推出的架构，RTX 30 系列和 A100 都采用它。
- 类别（category）：GPU 用在什么地方，比如消费级用途或数据中心。
- GeForce：NVIDIA 面向消费级用途的 GPU 系列，比如玩游戏或个人工作站。
- 工作站（workstation）：用于 3D 设计、工程计算等专业工作的高性能台式电脑。
- 数据中心 GPU（data center GPU）：为 AI、云计算和大型系统打造的 GPU。较老的资料把这个类别叫作“Tesla”。
- 工作负载（workload）：程序交给 GPU 的工作类型，比如训练 AI 模型。
- 核心数量（core count）：核心的个数，往往只统计一种核心，看不到全貌。
- 单精度（single-precision）：32 位浮点运算（FP32），核心数量通常统计的就是这类单元。
- Hopper / Blackwell：Nvidia 分别在 2022 年和 2024 年推出的数据中心架构，集成了大量 Tensor Core，而核心数量并不把它们算在内。
- H100：2022 年推出的 Hopper 数据中心 GPU，面向 AI 和 HPC。
- 散热（cooling）：把 GPU 产生的热量带走，可以靠显卡自带的风扇，也可以靠服务器里的气流。
- 模块（module，SXM）：一种数据中心 GPU 形态，平放在服务器主板上，而不是插在 PCIe 插槽里，由服务器负责散热。
- CUDA：NVIDIA 的平台，用来编写在 NVIDIA GPU 上运行的程序，GeForce 和数据中心 GPU 都适用。
