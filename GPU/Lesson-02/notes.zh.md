# 架构与代

这一课讲 GPU 架构（architecture）和 GPU 代（generation）的区别。这两个词听起来相近，意思却不一样。

## GPU 和 CUDA

GPU（Graphics Processing Unit，图形处理器）是一种能同时执行大量运算的处理器。它最初是为图形处理设计的，如今也广泛用于 AI、仿真模拟、数据处理和大规模计算。

CUDA 是 Nvidia 提供的 GPU 编程方式。有了它，你就能把 GPU 用于通用计算，而不只是图形处理。

## 架构

架构指 GPU 芯片的内部设计。它不仅决定了有哪些核心，还决定了：

- 核心如何组织  
- 数据如何流动  
- 显存如何访问  
- 并行任务如何执行  

你可以把它理解为发动机的设计。两块 GPU 从外表看可能差不多，但架构不同，表现就会相差很大。

架构直接影响：

- 性能  
- 能效  
- 支持的功能  

每个新架构通常都是一次真正的变革，而不是小修小补。有的架构提升了原始性能，有的更注重能效，较新的架构则专攻 AI 和大规模工作负载。光线追踪、AI 加速这类功能，都是在架构层面引入的。

Nvidia 大约每一到两年发布一个新架构，这也是 GPU 发展如此迅速的主要原因之一。

## 代

代与 GPU 的构造无关，它说的是 GPU 用在什么地方。

Nvidia 的 GPU 主要服务于两大领域。第一个是普通用户：

- 游戏  
- 内容创作  
- 一般图形处理  

第二个是：

- 云系统  
- 数据中心  
- AI 训练  
- 科学计算  

第二个领域叫 HPC（High Performance Computing，高性能计算）。

## 产品名称

Nvidia 会根据 GPU 的使用场景，给它们起不同的名字：

- Tegra 用于移动设备和嵌入式系统。  
- GeForce 用于消费级 GPU。  
- RTX 用于专业工作负载。  
- Data Center GPU（数据中心 GPU）用于服务器。现在常见的型号有 A100、H100 以及更新的型号。  

> [!NOTE]
> 你可能还会见到两个老名字。Quadro 是专业 GPU 过去的品牌，后来被 RTX 取代。数据中心 GPU 过去叫“Tesla”，但这个名字现在基本不用了。

这说明 GPU 的重心已经从通用计算转向了 AI 和云基础设施。

## 架构和代相互独立

架构描述 GPU 是怎么造的，代描述 GPU 用在哪里。所以同一种架构可以出现在截然不同的产品里。

例如，RTX 3090 和 A100 都基于 Ampere 架构。RTX 3090 面向个人使用，A100 面向大规模计算。两者架构相同，用途却不同。

## GPU 的类别

GPU 面向各种不同的使用环境：

- 小型便携系统  
- 个人电脑  
- 专业工作负载  
- 大型数据中心  

每种环境的需求、限制和侧重点都不一样。Nvidia 会对同一种架构加以调整，让它适应所有这些环境。

## 一条简单的规则

- GPU 是怎么造的？→ 架构  
- GPU 用在哪里？→ 代  

## 为什么这很重要

有了这条规则，GPU 的名字就容易看懂了。它还能帮你避开一个常见误区：以为两块 GPU 只要架构相同就差不多。等你开始用 CUDA 给 GPU 编程，这些差别就会变得非常重要。

## 术语表

- GPU（Graphics Processing Unit，图形处理器）：一种能同时执行大量运算的处理器。
- CUDA：Nvidia 提供的 GPU 编程方式，用于通用计算，而不只是图形处理。
- AI（人工智能）：从数据中学习的软件；训练它主要是海量的矩阵运算，所以 GPU 对它如此重要。
- 架构（architecture）：GPU 芯片的内部设计，就像发动机的设计。
- 能效（efficiency）：GPU 每消耗一瓦电能完成多少工作。
- 光线追踪（ray tracing）：通过追踪光线的反弹来绘制 3D 场景的方法，能得到逼真的阴影和反射；RTX GPU 有专门的硬件来做这件事。
- 代（generation）：GPU 的使用场景，比如游戏或数据中心。
- 数据中心（data center）：放满服务器的机房，往往装有成千上万块 GPU，用来运行云服务和 AI 训练。
- HPC（High Performance Computing，高性能计算）：指云系统、数据中心、AI 训练和科学计算。
- Tegra：Nvidia 用于移动设备和嵌入式系统的 GPU 产品名。
- 嵌入式系统（embedded system）：内置在设备里的小型计算机，比如机器人、汽车或无人机里的那种。
- GeForce：Nvidia 面向消费级 GPU 的品牌，用于游戏和个人电脑。
- RTX：Nvidia 给带光线追踪硬件的 GPU 起的名字，既用于 GeForce 显卡（RTX 3090），也用于专业显卡。
- Data Center GPU（数据中心 GPU）：Nvidia 用于服务器的 GPU，比如 A100 或 H100。
- Ampere：Nvidia 的一种架构，RTX 3090 和 A100 都用它。
- A100：Nvidia 2020 年推出的数据中心 GPU，基于 Ampere，专为 AI 训练和 HPC 打造。
