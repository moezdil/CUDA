# 架构与代

这一课讲 GPU 架构（architecture）和 GPU 代（generation）的区别。这两个词听起来很像，但意思不一样。

## GPU 和 CUDA

GPU（Graphics Processing Unit，图形处理器）是一种能同时执行大量运算的处理器。它最初是为图形设计的。今天它也用于 AI、仿真模拟、数据处理和大规模计算。

CUDA 是 Nvidia 提供的 GPU 编程方式。有了它，你可以把 GPU 用在通用计算上，而不只是图形。

## 架构

架构是 GPU 芯片的内部设计。它不只规定了有哪些核心，还规定了：

- 核心怎么组织  
- 数据怎么流动  
- 显存怎么访问  
- 并行工作怎么执行  

你可以把它想成发动机的设计。两个 GPU 从外面看可能差不多，但因为架构不同，表现会差很多。

架构直接影响：

- 性能  
- 能效  
- 支持的功能  

每一代新架构通常都是一次真正的转变，而不是小升级。有些架构提升了原始性能，有些更注重能效，较新的架构则专注于 AI 和大规模工作负载。光线追踪和 AI 加速这样的功能，都是在架构层面引入的。

Nvidia 大约每一到两年发布一个新架构。这是 GPU 发展这么快的主要原因之一。

## 代

代和 GPU 怎么造无关，它说的是 GPU 用在哪里。

Nvidia 的 GPU 主要服务两个世界。第一个是普通用户：

- 游戏  
- 内容创作  
- 一般图形处理  

第二个是：

- 云系统  
- 数据中心  
- AI 训练  
- 科学计算  

第二个世界叫 HPC，也就是高性能计算（High Performance Computing）。

## 产品名称

Nvidia 会根据 GPU 的使用场景起不同的名字：

- Tegra 用于移动设备和嵌入式系统。  
- GeForce 用于消费级 GPU。  
- RTX 用于专业工作负载。  
- Data Center GPU（数据中心 GPU）用于服务器。现在常见的型号有 A100、H100 以及更新的型号。  

> [!NOTE]
> 你可能还会看到两个老名字。Quadro 是以前专业 GPU 的品牌，后来被 RTX 取代。数据中心 GPU 以前用 “Tesla” 这个名字，但现在基本不用了。

这说明 GPU 的重心已经从通用计算转向了 AI 和云基础设施。

## 架构和代互不相关

架构描述 GPU 是怎么造的，代描述 GPU 用在哪里。所以同一个架构可以出现在完全不同的产品里。

例如，RTX 3090 和 A100 都基于 Ampere 架构。RTX 3090 面向个人使用，A100 面向大规模计算。它们架构相同，但用途不同。

## GPU 的类别

GPU 是为不同的环境打造的：

- 小型便携系统  
- 个人电脑  
- 专业工作负载  
- 大型数据中心  

每种环境都有不同的需求、限制和优先级。Nvidia 会调整同一个架构，让它适应所有这些环境。

## 一条简单的规则

- GPU 是怎么造的？→ 架构  
- GPU 用在哪里？→ 代  

## 为什么这很重要

这条规则能让你更容易看懂 GPU 的名字。它还能帮你避免一个常见错误：以为两个 GPU 只要架构相同就差不多。等你开始用 CUDA 给 GPU 编程时，这些差别会非常重要。

## 术语表

- GPU：一种能同时执行大量运算的处理器。
- CUDA：Nvidia 提供的 GPU 编程方式，用于通用计算，而不只是图形。
- 架构（architecture）：GPU 芯片的内部设计，就像发动机的设计。
- 代（generation）：GPU 用在哪里，比如游戏或数据中心。
- HPC：高性能计算（High Performance Computing），指云系统、数据中心、AI 训练和科学计算。
- Ampere：Nvidia 的一种架构，RTX 3090 和 A100 都用它。
- Tegra：Nvidia 用于移动设备和嵌入式系统的 GPU 产品名。
- Data Center GPU（数据中心 GPU）：Nvidia 用于服务器的 GPU，比如 A100 或 H100。
