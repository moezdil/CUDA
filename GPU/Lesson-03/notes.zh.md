# 看懂 GPU 规格

这一课教你怎样查出一块 GPU 的代和架构，以 RTX 3090 和 A100 为例。

## 查找 GPU 规格

最简单的办法是用 Google 搜索。例如：

"A100 GPU TechPowerUp"

TechPowerUp 是一个网站，收录了众多厂商 GPU 的详细规格，是查询 GPU 信息最方便的地方之一。其他 GPU 也可以用同样的方法搜索：

"RTX 3090 TechPowerUp"

打开页面，就能看到全部规格。

## 一个简单的对比

我们来比较两块 GPU：

- RTX 3090  
- A100  

首先看芯片名称。例如，A100 → GA100。

> [!NOTE]
> 芯片设计会在后面的课里讲。现在只要认得这个名字就行。

接着看核心数量：

- A100 → 大约 7,000 个核心  
- RTX 3090 → 超过 10,000 个核心  

但这并不意味着 RTX 3090 总是更强，因为核心数量并没有涵盖所有种类的核心。

## 核心数量

像“6,912 个核心”（A100）这样的数字，通常只统计单精度核心，也就是负责标准浮点运算的核心。它并不包括 GPU 里的所有核心。

现代 GPU 还有其他类型的核心，例如：

- 负责整数运算的核心  
- 负责双精度运算的核心  
- 专门用于 AI 的核心（Tensor Core）

所以不要只凭这一个数字来评判 GPU。

## 代与架构

### RTX 3090

- 代 → GeForce  
- 架构 → Ampere  

GeForce GPU 面向普通用户，常见于：

- 台式机  
- 笔记本电脑  
- 工作站  

主要用途：

- 游戏  
- 内容创作  
- 常规的 GPU 任务  

### A100

- 代 →（以前叫 Tesla，现在叫 Data Center GPU）  
- 架构 → Ampere  

这类 GPU 面向以下场景：

- 服务器  
- 数据中心  
- 超级计算机  

## 要点

- RTX 3090 和 A100 采用的是同一种架构（Ampere）  
- 但两者的用途截然不同  

架构相同 ≠ 用途相同。

提醒一下：
- 架构 → 技术设计
- 代 → 使用类别

## 从外观上区分

很多时候，看一眼显卡就能分辨出来。

### 数据中心 GPU（A100、V100、P100）

- 通常没有自带风扇  
- 紧凑的无风扇设计

它们运行在数据中心里，依靠强大的外部散热。负责散热的是服务器，而不是 GPU 本身。

### GeForce GPU（RTX 系列）

- 自带风扇  
- 为独立运行的系统设计  

它们装在：

- 台式电脑  
- 个人工作站  

这些系统要自己解决散热，所以显卡上需要风扇。

## 小结

- 数据中心 GPU → 没有风扇  
- GeForce GPU → 自带风扇  

环境不同，散热需求也不同。了解这一点能帮你：

- 看懂 GPU 规格  
- 选对硬件  
- 避免新手常犯的错误  

随着你对 CUDA 的学习不断深入，这些知识会越来越重要。

## 术语表

- 规格（specs）：GPU 公开的技术参数，比如核心数量、显存大小和时钟频率。
- TechPowerUp：一个收录众多厂商 GPU 详细规格的网站。
- RTX 3090：2020 年推出的 GeForce GPU，基于 Ampere，有 10,496 个核心和 24 GB 显存。
- A100：Nvidia 2020 年推出的数据中心 GPU，基于 Ampere，有 6,912 个单精度核心。
- 芯片名称（chip name）：GPU 内部芯片的名字，比如 A100 的芯片叫 GA100。
- 核心数量（core count）：规格里列出的核心数，并没有涵盖所有种类的核心。
- 单精度核心（single-precision cores）：负责标准浮点运算的核心，核心数量通常只统计它们。
- 浮点（floating-point）：带小数点的数，比如 3.14；单精度用 32 位存一个数，双精度用 64 位。
- 双精度（double-precision）：64 位浮点运算，用于科学计算；A100 在这方面比 RTX 3090 快得多。
- Tensor Core：现代 GPU 里专门为 AI 打造的特殊核心。
- 架构（architecture）：GPU 的技术设计。
- 代（generation）：GPU 的使用类别，比如 GeForce 或 Data Center GPU。
- Ampere：RTX 3090 和 A100 共用的架构。
- GeForce：Nvidia 面向台式机、笔记本电脑和工作站的消费级 GPU，自带风扇。
- 工作站（workstation）：用于专业工作（比如 3D 设计或工程计算）的高性能台式电脑。
- Tesla：Nvidia 数据中心 GPU 以前的名字，现在叫 Data Center GPU。
- Data Center GPU（数据中心 GPU）：Nvidia 用于服务器的 GPU，比如 A100，通常没有自己的风扇。
- 数据中心（data center）：放满服务器的机房，靠强力风扇和空调散热。
- 超级计算机（supercomputer）：成千上万台互联的服务器，像一台机器一样协同处理超大规模的问题。
- V100 / P100：较早的 Nvidia 数据中心 GPU，分别基于 Volta（2017）和 Pascal（2016）。
- 无风扇（fanless）：显卡上只有散热片，没有风扇；靠服务器自己的风扇把气流吹过散热片。
- 散热（cooling）：把 GPU 产生的热量带走；GeForce 显卡靠自己的风扇，数据中心显卡则依靠服务器。
