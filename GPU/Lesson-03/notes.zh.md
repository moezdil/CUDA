# 看懂 GPU 规格

这一课教你怎样查到一个 GPU 的代和架构。我们用 RTX 3090 和 A100 作为例子。

## 查找 GPU 规格

最简单的办法是用 Google 搜索。例如：

"A100 GPU TechPowerUp"

TechPowerUp 是一个网站，收集了很多厂商的详细 GPU 规格。它是查 GPU 信息最方便的地方之一。你可以用同样的方法搜索其他 GPU：

"RTX 3090 TechPowerUp"

打开页面，就能看到全部规格。

## 一个简单的对比

我们来比较两个 GPU：

- RTX 3090  
- A100  

首先，看芯片名称。例如，A100 → GA100。

> [!NOTE]
> 芯片设计会在后面的课里讲。现在你只需要读一下这个名字。

接着，看核心数量：

- A100 → 大约 7,000 个核心  
- RTX 3090 → 超过 10,000 个核心  

这并不说明 RTX 3090 总是更强，因为核心数量并没有把所有种类的核心都算进去。

## 核心数量

像 “6,912 个核心”（A100）这样的数字，通常只统计单精度核心。这些核心负责标准的浮点运算。这个数字并不包括 GPU 里的所有核心。

现代 GPU 还有其他类型的核心，例如：

- 负责整数运算的核心  
- 负责双精度运算的核心  
- 专门用于 AI 的核心（Tensor Core）

所以不要只凭这一个数字来判断 GPU。

## 代与架构

### RTX 3090

- 代 → GeForce  
- 架构 → Ampere  

GeForce GPU 面向普通用户，用在：

- 台式机  
- 笔记本电脑  
- 工作站  

主要用途：

- 游戏  
- 内容创作  
- 一般的 GPU 任务  

### A100

- 代 →（以前叫 Tesla，现在叫 Data Center GPU）  
- 架构 → Ampere  

这类 GPU 是为以下场景打造的：

- 服务器  
- 数据中心  
- 超级计算机  

## 要点

- RTX 3090 和 A100 使用的是同一个架构（Ampere）  
- 但它们是为完全不同的用途打造的  

架构相同 ≠ 用途相同。

提醒一下：
- 架构 → 技术设计
- 代 → 使用类别

## 从外观上区分

很多时候，你只要看一眼显卡就能分辨出来。

### 数据中心 GPU（A100、V100、P100）

- 通常没有自带风扇  
- 紧凑的无风扇设计

它们运行在数据中心里，有强大的外部散热。散热由服务器负责，而不是 GPU 自己。

### GeForce GPU（RTX 系列）

- 自带风扇  
- 为独立的系统设计  

它们运行在：

- 台式电脑  
- 个人工作站  

这些系统需要自己散热，所以显卡上要有风扇。

## 小结

- 数据中心 GPU → 没有风扇  
- GeForce GPU → 自带风扇  

不同的环境有不同的散热需求。了解这一点能帮你：

- 看懂 GPU 规格  
- 选对硬件  
- 避免新手常犯的错误  

随着你深入学习 CUDA，这些知识会变得越来越重要。

## 术语表

- TechPowerUp：一个收集了很多厂商详细 GPU 规格的网站。
- 芯片名称（chip name）：GPU 里芯片的名字，比如 A100 的芯片叫 GA100。
- 核心数量（core count）：规格里列出的核心数，它并没有把所有种类的核心都算进去。
- 单精度核心（single-precision cores）：负责标准浮点运算的核心，核心数量通常只统计它们。
- Tensor Core：现代 GPU 里专门为 AI 打造的特殊核心。
- 架构（architecture）：GPU 的技术设计。
- 代（generation）：GPU 的使用类别，比如 GeForce 或 Data Center GPU。
- Ampere：RTX 3090 和 A100 共用的架构。
