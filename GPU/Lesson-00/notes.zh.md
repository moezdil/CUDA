# CPU 与 GPU 基础

这一课讲 GPU 和 CPU 有什么不同，还会带你看看 GPU 内部有什么。

## 光把代码搬到 GPU 上还不够

代码从 CPU 搬到 GPU 上跑，并不会自动变快。只有当你理解 GPU 的工作方式，才能拿到好的性能。

## 目标不同

CPU 和 GPU 都能处理数据、执行指令。但它们是为完全不同的目标设计的。

CPU 的设计重点是：

- 响应快  
- 能处理复杂逻辑  
- 顺序执行（一步接一步）  

GPU 的设计重点是同时处理很多事情。

- CPU：一个复杂任务，做得非常快  
- GPU：很多简单任务，并行完成  

## 内存

CPU 使用系统内存（RAM）。所有数据都经过同一块共享的内存空间。

GPU 有自己的内存，叫 VRAM，也就是显存。这意味着：

- CPU 和 GPU 不会自动共享数据  
- 数据必须在两者之间复制  

这个复制过程可能成为瓶颈，所以要小心处理。

## 缓存与共享内存

缓存是一块很小、速度很快的存储，离处理器很近。CPU 和 GPU 都有缓存，但用法不一样。

> [!NOTE]
> CPU 依赖多级缓存：L1、L2 和 L3。它们容量小，但速度非常快。

GPU 也有缓存。它还多了一样东西，叫共享内存。GPU 里的线程用它来协作、交换数据。共享内存是 GPU 优化最关键的工具之一。

## 核心速度

GPU 更强，并不是因为每个核心更快。单个 CPU 核心的时钟频率通常更高，常常有好几 GHz。单个 GPU 核心要慢一些。如果一个核心对一个核心比，CPU 会赢。

## GPU 的力量从哪里来

GPU 有很多简单的核心。它把工作拆成很多小块，同时运行。它的力量来自大量核心一起干活，而不是单个核心有多强。

只有当问题能拆成并行的小块时，GPU 才更有优势。如果是顺序执行的任务，CPU 很可能比 GPU 快得多。

## CPU 和 GPU 如何配合

GPU 不是单独工作的。在一个典型的系统里：

- CPU 负责管理程序  
- GPU 负责运行并行的工作  

它们通过 PCIe 这样的连接通信。数据流大致是这样：

CPU → 把数据发给 GPU  
GPU → 处理数据  
GPU → 把结果发回来  

如果这个流程处理得不好，性能就会下降。

## 流式多处理器（SM）

GPU 里最重要的单元是流式多处理器（Streaming Multiprocessor，SM）。SM 是一个小型处理单元。一个 GPU 就是很多个 SM 一起工作。

每个 SM 都具备运行并行工作所需的一切：

- 寄存器，速度最快的存储  
- 共享内存，线程在这里交换数据  
- 控制单元，决定运行什么、什么时候运行  
- 执行单元，负责真正干活  

## 执行单元

每个 SM 里有不同类型的计算单元，每种都有专门的用途：

- 浮点单元，在图形和 AI 中用得很多  
- 整数单元  
- Tensor Core，用于矩阵运算，对 AI 至关重要  
- 特殊函数单元，用于更复杂的数学运算  
- 加载/存储单元，负责在显存和计算单元之间搬运数据  

所以 GPU 不只是“很多核心”。它是一个由各种专用单元组成的、有结构的系统。

## L2 缓存

L2 缓存是整个 GPU 共用的一层缓存。它不像 L1 或共享内存那样属于某一个 SM。它更大，但也更慢。它能帮助降低访问显存的开销。

## 为什么这很重要

CUDA 不只是写代码，更是要理解硬件。想用好 GPU，你需要知道：

- 显存是怎么工作的  
- 并行执行是怎么工作的  
- 数据是怎么流动的  

GPU 编程就是用并行的方式思考。这个思路是后面所有 CUDA 内容的基础。

## 术语表

- GPU（图形处理器）：有成千上万个简单核心的处理器，专门用来并行处理大量任务。
- CPU（中央处理器）：计算机的主处理器，擅长快速响应、复杂逻辑和顺序执行的工作。
- 顺序执行（sequential execution）：一步接一步地执行，每一步都要等前一步做完。
- 并行（parallel）：很多任务同时运行，而不是一个接一个。
- 系统内存（system RAM）：主板上的计算机主内存，由 CPU 使用。
- VRAM：GPU 自己的显存，和 CPU 使用的系统内存是分开的。
- 瓶颈（bottleneck）：一条流程中最慢的那一步，它限制了整条流程的速度。
- 缓存（cache）：一块很小、速度很快的存储，离处理器很近。
- L1 缓存（L1）：最小、最快的一级缓存，紧挨着核心（在 GPU 上位于每个 SM 内部）。
- 共享内存（shared memory）：GPU 上供线程协作、交换数据的一块内存。
- 线程（thread）：一条指令流；GPU 可以同时运行成千上万个线程。
- 核心（core）：执行指令的一个处理单元；CPU 有几个强大的核心，GPU 有成千上万个简单的核心。
- 时钟频率（clock speed）：单个核心运行的速度，CPU 上常常有好几 GHz。
- GHz（吉赫兹）：每秒十亿个时钟周期，所以 3 GHz 的核心每秒跳动 30 亿次。
- PCIe（PCI Express）：CPU 和 GPU 之间互相传送数据的一种连接。
- SM（流式多处理器）：GPU 里最重要的处理单元，一个 GPU 就是很多个 SM。
- 寄存器（register）：SM 里速度最快的存储；每个线程把自己的变量放在寄存器里。
- 浮点单元（floating-point unit）：对带小数点的数（比如 3.14）做运算的单元。
- Tensor Core：SM 里专门做矩阵运算的计算单元，对 AI 至关重要。
- 特殊函数单元（special function unit，SFU）：用硬件计算正弦、余弦、平方根等函数的单元。
- 加载/存储单元（load/store unit）：在内存和计算单元之间搬运数据的单元。
- L2 缓存：更大但更慢的缓存，整个 GPU 共用，不属于某一个 SM。
- CUDA（Compute Unified Device Architecture）：NVIDIA 的平台，用来编写在其 GPU 上运行的通用程序。
