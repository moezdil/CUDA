# GPU 简史

这一课介绍 GPU 是怎样一步步成长为强大的计算平台的。在写 CUDA 代码之前，先了解这些背景会很有帮助。

## 早期

Nvidia 成立于 90 年代初，没过多久就发布了第一款产品。

> [!NOTE]
> Nvidia 和今天很多大型科技公司差不多是同一时期起步的。

和今天相比，那时的硬件非常简单：

- 显存很小  
- 数据带宽非常有限  
- 几乎没有真正的并行  

## 现代 GPU

今天的 GPU 完全是另一个量级。它们：

- 拥有几千个，甚至几万个核心  
- 拥有很大的显存  
- 运行频率高得多  

它们的角色也变了。

## 不只是图形

GPU 最初是为渲染图像而设计的。如今这只是它工作中很小的一部分。现在 GPU 广泛用于：

- 人工智能  
- 大规模数据处理  
- 仿真模拟  
- 科学计算  

所以现代 GPU 是一个计算平台，而不只是一个图形设备。

## 第一个转折点

一个关键时刻是 GPU 开始支持真正的 3D 加速。这让 GPU 对更多人有用，而不只是少数专业人士。GPU 的普及速度很快。

## GeForce

不久之后，Nvidia 推出了 GeForce 系列。GPU 第一次变得随处可以买到。即使是早期的 GeForce 显卡，也带来了更多并行、更大的显存和更多功能。因为起点还很低，核心数量或显存上的一点点提升，都会带来很大的变化。

## 稳步成长

之后，进步越来越快。每一代都在性能、能效或功能上有所提升。这些提升随着时间不断累积。现代 GPU 之所以强大，是多年来一步步积累的结果，而不是一次大跳跃。

## 今天的位置

今天，Nvidia 在这些领域都扮演着核心角色：

- 游戏  
- AI 基础设施  
- 云计算  
- 高性能计算  

在很多场景中，GPU 已经成为现代 AI 系统的主要动力。

## 学 CUDA 之前为什么要了解这些

了解 GPU 的演变过程，能帮你理解：

- 为什么架构会设计成现在这样  
- 为什么不同 GPU 的性能会有差别  
- 为什么现代 GPU 会有这些功能  

这样你再学 CUDA 就会更轻松。

## 术语表

- GPU（图形处理器）：有成千上万个简单核心的处理器，专门用来并行处理大量任务。
- Nvidia：成立于 1993 年的公司，生产 GeForce 和数据中心 GPU，并创造了 CUDA。
- 数据带宽（data bandwidth）：GPU 能搬运多少数据，早期硬件在这方面非常有限。
- 并行（parallelism）：同时做很多事情，早期 GPU 几乎做不到。
- 核心（core）：真正干活的单元，现代 GPU 有几千个。
- 频率（frequency）：GPU 运行的速度，现代 GPU 的频率高得多。
- 渲染（render）：把对场景的描述（形状、颜色、光照）变成你在屏幕上看到的像素。
- AI（人工智能）：从数据中学习的软件，比如图像识别或聊天机器人；训练它主要是海量的矩阵运算，正适合 GPU。
- 计算平台（compute platform）：用于通用计算的设备，而不只是用于图形。
- 3D 加速：GPU 对 3D 图形的支持，它让 GPU 对更多人有用。
- GeForce：Nvidia 的 GPU 系列，它第一次让 GPU 变得随处可以买到。
- 一代（generation）：GPU 发布中的一步，每一代都会在性能、能效或功能上有所提升。
- 能效（efficiency）：GPU 每消耗一瓦电能完成多少工作。
- 云计算（cloud computing）：通过互联网租用服务商数据中心里的计算机（包括 GPU），而不是自己购买硬件。
- 高性能计算（HPC）：很多强大的处理器一起解决大问题，比如天气或物理仿真。
- 架构（architecture）：GPU 的整体设计，也就是它的核心、显存和各种单元是怎样组织的。
- CUDA（Compute Unified Device Architecture）：NVIDIA 的平台，用来编写在其 GPU 上运行的通用程序，2007 年首次发布。
